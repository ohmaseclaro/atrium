## [0.3.0] — first public release

First public minor release of the Atrium remote-browser stack across all six packages: `@atriumjs/protocol`, `@atriumjs/core`, `@atriumjs/express`, `@atriumjs/worker`, `@atriumjs/react`, `@atriumjs/cli`.

### Highlights

- **Tenant-scoped authorization** on every per-session HTTP route.
- **URL allowlist enforced on viewer-driven navigation** (both WebSocket `navigate` and `POST /sessions/:id/stream/input`).
- **`publicBaseUrl` defense** — viewer URLs derive from configured base, not the request `Host` header.
- **Timing-safe credential compare** for `ATRIUM_WORKER_SECRET` and viewer tokens.
- **In-process janitor** enforcing `sessionTtlMs` and `idleTtlMs`; `createAtrium()` returns a `dispose()` to stop it cleanly.
- **mTLS client certificate support** (PEM or PFX bundles on `POST /sessions`).
- **Passkey-aware viewer** — the worker disguises Chromium as a device without a platform authenticator; `<RemoteBrowser />` shows a graceful toast if a site insists.
- **Multi-tab support** — `target="_blank"` opens a managed tab and emits `tabs` over the viewer WebSocket.
- **Session snapshots** — single JSON blob mirroring Playwright `storageState` shape; works as request bootstrap or post-init apply.
- **Stealth Chromium under Xvfb headed-by-default**, with `playwright-extra` + `puppeteer-extra-plugin-stealth`.
- **Automatic reconnect** in `<RemoteBrowser />` with replay and 20s ping/pong heartbeat.
- **IME composition forwarded** as `t: "ime"`; CJK no longer double-fires.
- **Held modifiers flushed** on `blur` / `visibilitychange` / `pointercancel` so Cmd-Tab doesn't strand a held Cmd.
- **Wheel deltas scaled** to the remote viewport with `deltaMode` normalization.
- **Imperative React handle**: `reconnect`, `navigate`, `back`, `forward`, `reload`, `requestControl`, `releaseControl`.
- **Optional viewer chrome presets**: `none`, `minimal`, `full`, or custom `{ showTabStrip?, showToolbar?, showUrlBar? }`.
- **Cursor / favicon / loading** server messages drive UI; control pill is server-authoritative and a11y-friendly.
- **Tab strip a11y**: roving tabindex, manual activation, arrow / Home / End / Delete bindings.
- **Provenance-enabled npm publishes** via `changesets/action@v1` on tag push / release.

### Out of scope for 0.3.0 (designed, not shipped)

These are tracked in [`docs/atrium-v2-design.md`](docs/atrium-v2-design.md) and on the roadmap:

- BullMQ-backed allocator for >50 concurrent sessions per node.
- Multi-region demo orchestration.

## Conventions

- One root entry per release tag (e.g. `0.3.0`, `0.4.0`).
- Per-package detail lives in the per-package changelogs and is the source of truth — the root file is a summary for humans landing on the repo.
- Security-relevant changes are highlighted in their own "Security" sub-section.
- The "[Unreleased]" section is appended to as PRs land; on release it gets renamed to the new tag and a fresh empty one is added on top.

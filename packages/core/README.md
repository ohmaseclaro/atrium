# @atriumjs/core

Framework-agnostic Atrium HTTP and streaming surface: `createAtrium()` returns handlers you can wire from Express, Fastify, or any runtime that can map requests to Web `Request`/`Response` and Node WebSocket upgrades.

See the [v2 design doc](../../docs/atrium-v2-design.md) for the full architecture. Express integration lives in `@atriumjs/express`.
